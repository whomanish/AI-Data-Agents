# Preview limitations

This build is intended for early installation and controlled local testing.

It is not:

- a production release.
- approved for production PII or recipient data.
- authorized to send, upload, publish, schedule, or activate campaigns.
- certified for ChatGPT app, Claude app, or Claude Code installation.
- independently validated production behaviour.
- a claim of final performance, compatibility, or support.

The preview has positive controlled evidence for advisory routing, material
clarification, safe handling of failed quick checks, instruction-like source
data, external-action withholding, and a local non-sending audience pipeline.

The following areas are not yet claimed by this preview:

- operation with live production datasets or recipient records.
- installation and consistent behaviour outside local Codex.
- connection to every possible analytics, CRM, messaging, or in-app system.
- end-to-end activation against a real destination.
- production-scale performance, reliability, or support.
- independently verified behaviour across unfamiliar environments and data.

These boundaries do not prevent safe evaluation with fictional or explicitly
approved local test data. They do mean that a successful preview test should
not be treated as authorization or evidence of production readiness.

All mutable overlays and campaign artifacts must remain outside the installed
skill. The bundled overlay is an empty template, not organization data.
