# Environment and access

Establish the overlay location and its read, write, and persistence behaviour; campaign-workspace access; deterministic execution and Python availability; relevant network limits; and each required connector operation. Record operation-level evidence, not an assumption based on a host or connector name.

If an operation is unknown, treat the corresponding outcome as unsupported until a safe check establishes it. Do not test production writes to discover access. When storage is session-only, disclose that durable readiness cannot be claimed without validated export and restoration. When a source or channel operation is unavailable, offer the approved file handoff or local-agent path.

Ready evidence includes the tested operation, scope, observation method, constraints, date, and owner where applicable. Keep credentials, tokens, recipient data, and full results out of state. Email and in-app differ only in their required source and channel operations; each still needs a confirmation-gated external write path for activation.
