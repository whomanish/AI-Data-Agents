# Changelog

## 0.1.0-preview.1

- First installable early-testing preview derived from a verified immutable
  source snapshot.
- Includes the canonical skill entrypoint, local control and pipeline scripts,
  schemas, references, metadata, and blank overlay template.
- Excludes evaluation suites, blind-evaluation machinery, build history,
  captured evidence, production data, credentials, and campaign outputs.
- Supports controlled local non-sending demonstrations only.
- Adds deterministic packaging, an offline smoke checker, and explicit
  in-package preview labeling.
