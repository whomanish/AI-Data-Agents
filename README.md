# AI Data Agents

Open-source agents and skills that turn data into useful, reviewable work while
keeping consequential actions under human control.

## Projects

### [Product Usage Outreach](product-usage-outreach/)

Product Usage Outreach helps product, growth, and lifecycle teams answer a
practical question: **which users should receive which product message, and
why?**

Give it a product behaviour to investigate, such as active users who have not
adopted a valuable feature. It can then help:

- define the behaviour and observation window precisely.
- identify a qualifying cohort from approved usage data.
- apply identity, eligibility, suppression, and holdout rules.
- prepare an email or in-app campaign plan and measurement approach.
- produce a reviewable handoff without sending anything automatically.

[See what the skill does and try a synthetic example](product-usage-outreach/).

> **Preview / early testing:** The current release is not approved for
> production data or external campaign actions. Read its
> [limitations](product-usage-outreach/docs/PREVIEW_LIMITATIONS.md) before use.

Installation, testing, checksums, and release evidence are documented inside
the project directory and attached to its GitHub pre-release.
